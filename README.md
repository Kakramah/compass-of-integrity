# أصلح بوصلتك

مقالة تفاعلية عن الثبات على المبدأ والنجاة بالفطرة، مع ميزان متحرك وبوصلة يوجهها القارئ.

الموقع: https://kakramah.github.io/compass-of-integrity/

## التشغيل
موقع ثابت بلا اعتماديات خارجية. افتح index.html أو شغّل `python3 -m http.server 8000`.
مصدر النشر هو الفرع الرئيسي بعد مراجعة طلب الدمج. .nojekyll يبقي الملفات كما هي.

## الحقوق والمحتوى
Amiri وNoto Naskh Arabic مرخصان برخصة SIL Open Font License 1.1، وتوجد نسخة الترخيص في fonts/.
مصادر التراخيص: https://github.com/google/fonts/blob/main/ofl/amiri/OFL.txt وhttps://github.com/google/fonts/blob/main/ofl/notonaskharabic/OFL.txt.
الصور تصورات مولدة من النسخة التي اعتمدها خلدون للنشر، وليست توثيقاً لأشخاص أو أحداث. النص التأملي بلا نسبة مؤلف غير مثبتة.
لا تسجيل صوتي مرفق: يمكن اختيار ملف صوتي محلي وتشغيله في المتصفح فقط. لا يُرفع الملف إلى خادم.

## الفحص
بوابة الويب من مشروع khaldoun-web-starter، وفحص Chrome بعروض 375 و390 و1440 وبالحركة المخففة. تفاصيل النتيجة في طلب الدمج.
